Brandbook Generator

How to use

This site is what the tool produces. The tool is the repo it came from — it runs inside Claude Code on your machine, and your brand never leaves it unless you publish.

1

Clone it and open Claude Code

You need Claude Code and Node 18+.

git clone https://github.com/buildersstudio/brandbook-generator.git cd brandbook-generator claude

Claude reads CLAUDE.md on open, so it already knows the workflow.

2

Point it at your brand

Say what carries your brand — a website, a deck, a folder of screenshots and logos. A live site is the richest input.

My website is acme.example — build my brandbook.

Claude fetches the site, pulls the real logo files, the CSS palette, the font stacks, the imagery and the copy, and asks you only what it genuinely cannot infer.

3

It writes the data, then renders the site

Everything lands in one structured file, brand-book.json — the source of truth. The renderer turns it into these seven pages:

node render.mjs

Your assets go in assets/, and the book replaces this one at the root of the repo.

4

Iterate in plain words

React to what you see. Claude edits the JSON and re-renders — you never hand-edit HTML.

The green is wrong, use the darker one from our logo. And our voice is warmer than this.
5

Publish it

The book runs on localhost by default (./serve.sh). Publishing is what makes it useful to the rest of your stack.

Publish my brandbook.

Claude walks you through Vercel or GitHub Pages — see PUBLISH.md.

Why publish

A published brandbook is the source of truth every other tool in the Builders toolkit reads from — ask the Post Generator for a LinkedIn post and it already knows your colors, your fonts, your voice, and which claims are real. It is also your marketing repository: one link that answers every “what is our hex / font / tagline” question.

What lives where

brand-book.jsonYour brand as structured data. The one file other tools read.
assets/Your logos and photography, referenced by path from the JSON.
render.mjsThe renderer. Zero dependencies — JSON plus template in, site out.
template/The page templates. Edit these to change how every book looks.
schema.mdThe field-by-field contract for brand-book.json.
CLAUDE.mdThe operating manual Claude follows.
