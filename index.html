How it works

Three steps, one afternoon

There is no app and no API — the tool runs inside Claude Code on your machine. You talk, it builds.

1

Point

Clone the repo, open it in Claude Code, and say what your brand is: a website URL, a pitch deck, a folder of screenshots and logos. Anything that carries your brand works as input.

2

Distill

The generator extracts your logo, palette, type system, spacing, photography style, and voice — and writes them into one structured brand-book.json plus a rendered brandbook site.

3

Publish

The book lives on localhost by default. When you're ready, one command publishes it to a public link (Vercel or GitHub Pages) so your team — and your other tools — can point at it.

What you get

A real brandbook, not a moodboard

The same structure we use for the ventures in our studio. Six chapters, each specific enough that a designer, a copywriter, or another tool can act on it.

🔖

Logo

Primary, inverse, and lettermark variants with clear-space rules and explicit do's and don'ts.

🎨

Colors

Grouped swatches with hex values, usage notes, and WCAG contrast guidance.

🔤

Typography

Font roles and stacks, a full type scale, weights, and a live pairing example.

📐

Spacing & Layout

Spacing tokens, border radii, and shadows — the quiet system behind consistent design.

📷

Photography

Style direction, framing rules, reference subjects, and the color accents imagery should carry.

💬

Messaging

Voice, headline formulas, proof points, and example headlines — what every post and page should sound like.
